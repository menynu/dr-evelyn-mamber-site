# מרפאת ד״ר אוולין ממבר

אתר סטטי בעברית (מימין לשמאל) עם עמוד באנגלית, ומענה אוטומטי לשאלות נפוצות.
אין מסד נתונים, אין מנוי, ואין עלות של מודל שפה. אפשר לארח בחינם ב־GitHub Pages, ב־Cloudflare Pages או ב־Vercel.

הקהל הוא הורים לילדים בירושלים. הטלפון באתר: 02-5611949.

## לפני שמפרסמים

פתחו את `clinic.config.mjs` בלבד. זה הקובץ היחיד של פרטי המרפאה.
אל תעלו את האתר לאוויר עד שד״ר ממבר אישרה את הרשימה הזו:

1. **כתובת.** אושרה: חזקיהו המלך 36, ירושלים. `addressConfirmed` הוא `true`. באנגלית: 36 Hezkiyahu HaMelech Street. לא מחליפים רחוב בלי אישור חדש, ומשנים את `streetHe` ו־`streetEn` יחד.
2. **שעות.** `hoursConfirmed` נשאר `false`. השעות בקובץ הן מציין מקום והאתר לא מציג אותן. אחרי אישור משנים את השעות ואת הדגל ל־`true`.
3. **וואטסאפ.** `whatsappReady` הוא `false`. `whatsappNumber` חייב להיות נייד שמקבל וואטסאפ, בלי + ובלי מקפים (למשל `972501234567`). המספר 02 הוא קווי, והערך הנוכחי הוא רק תרגום שלו לפורמט בינלאומי. עד שמוחלף נייד ובודקים שהודעה מגיעה, האתר מחייג במקום לפתוח וואטסאפ.
4. **דוא״ל, קופות חולים, חניה ונגישות הבניין.** השדות ריקים בכוונה. לא ממלאים קופה שלא אושרה.
5. **הזיקה להדסה.** המשפט על הוראה בהתנדבות באוניברסיטה העברית–הדסה מסומן באתר כממתין לאישור. אם הניסוח לא מדויק, עורכים את `affiliationHe` ו־`affiliationEn`, או מכבים עם `showAffiliation: false`.
6. **תואר רישום.** `isRegisteredSpecialist` הוא `true`. האתר מציג רק «מומחית לרפואת שיניים לילדים» / Specialist in Pediatric Dentistry. לא מוסיפים תואר אחר. אם הרישום לא בתוקף, מחזירים את הדגל ל־`false`.
7. **אימות גוגל.** `googleSiteVerification` נשאר ריק עד שמדביקים את קוד Search Console (רק הערך, בלי תגית HTML). ריק = אין תגית meta באתר.
8. **כתובת האתר.** `siteUrl` הוא `https://menynu.github.io` (בלי סלאש ובלי שם המאגר). האתר עצמו נפתח ב־`https://menynu.github.io/dr-evelyn-mamber-site/`. בדומיין פרטי מחליפים את `siteUrl` ומוחקים את `GITHUB_PAGES_BASE` מה־workflow.
9. **המלצות.** `testimonials` נשאר מערך ריק. לא ממציאים ציטוטים. כשמוסיפים, רק טקסט שההורה אישר לפרסם.
10. **מספר רישיון ורכז נגישות.** אופציונלי. ריק = לא מוצג שם.
11. **ניווט.** `lat` ו־`lng` הם נעץ הבניין חזקיהו המלך 36. אם הכניסה למרפאה במקום אחר, מעדכנים את שניהם. הכפתורים באתר נבנים מהם ומהכתובת.
12. **ביקורת בגוגל.** `googleReviewUrl` הוא קישור לכתיבת ביקורת. הערך הנוכחי משתמש ב־Place ID של כרטיס המרפאה. אם יש קישור קצר רשמי, מחליפים את כל הכתובת (ראו למטה). לא מבקשים רק ביקורת חיובית ולא מציעים הטבה.
13. **שליחת ניווט מהמחשב.** `navShareMode` נשאר `client` כל עוד אין שרת הודעות. במצב הזה המספר לא נשמר ולא נשלח לשרת של האתר.

אסור גם: «הכי», «הטוב ביותר», הבטחת תוצאה, מחירון כמבצע, וצילומי השוואה של שיניים.

דוגמה לטלפון:


`phoneDisplay` הוא מה שההורה רואה. `phoneTel` הוא לחיצה לחיוג, עם קידומת 972 ובלי מקף.

## שאלות נפוצות והמענה האוטומטי

השאלות נמצאות ב־`src/data/faq.json`, בעברית ובאנגלית.
המענה הוא סקריפט מקומי (`public/bot-core.js`). הוא מתאים מילים מהשאלה לרשימה. הוא לא פונה לאינטרנט ולא נותן ייעוץ רפואי.
במצב דחוף הוא מבקש להתקשר למרפאה, או לפנות לחדר מיון / מד״א 101.

אפשר לערוך ניסוח של תשובה (`a`) או מילות מפתח (`keywords`).
שומרים על הסוגריים `{{phone}}` ו־`{{address}}` כמו שהם: האתר ממלא אותם מתוך קובץ ההגדרות.
הכפתורים במענה הם: שעות פעילות, כתובת / ניווט, קביעת תור, ביקור ראשון, מקרה חירום, ביקורת בגוגל.
בתשובה על הכתובת מופיעים גם כפתורי Waze ו־Google Maps. בתשובה על הביקורת מופיע קישור לכתיבה בגוגל.

טופס «צור קשר» לא נשמר באתר. הוא פותח וואטסאפ או דוא״ל אצל ההורה, עם שם, טלפון, גיל וזמן מועדף בלבד.

## להריץ במחשב

צריך Node 22.

```bash
npm install
npm run dev
```

האתר נפתח בכתובת `http://127.0.0.1:4391`.

```bash
npm test
npm run check
npm run build
```

`npm run build` יוצר תיקייה `dist`. אותה מעלים לאחסון.

## Cloudflare Pages (חינם)

1. נכנסים ל־[Cloudflare Dashboard](https://dash.cloudflare.com/) → Workers & Pages → Create → Pages.
2. אם יש גיט: Connect to Git, בוחרים את המאגר.
   - Build command: `npm run build`
   - Build output directory: `dist`
   - משתנה סביבה: `NODE_VERSION` = `22`
3. בלי גיט: Direct Upload, ומעלים את תוכן התיקייה `dist` אחרי `npm run build`.
   כל שינוי בקובץ ההגדרות דורש בנייה והעלאה מחדש.
4. אחרי שהבנייה ירוקה: Custom domains → מוסיפים את הדומיין.
5. מעדכנים את `siteUrl` לאותו דומיין ובונים שוב, כדי שמפת האתר והקישורים הקנוניים יהיו נכונים.

## דומיין `.co.il`

קונים דומיין אצל רשם ישראלי (למשל Domain The Net, LiveDNS, Box, Galcomm).

**אם הרשם מאפשר להחליף שרתי שמות:** ב־Cloudflare מוסיפים את הדומיין, ומעתיקים אצל הרשם את שני שרתי השמות ש־Cloudflare נותן. אחר כך ב־Pages מחברים את הדומיין. זה המסלול הפשוט.

**אם אי אפשר להחליף שרתי שמות:** ב־Pages לוחצים Set up a custom domain ומעתיקים אצל הרשם את הרשומות שמופיעות שם (בדרך כלל CNAME ל־`www`). לכתובת בלי `www` לא כל רשם `.co.il` תומך ב־CNAME. במקרה כזה משאירים את האתר על `www` ומבקשים מהרשם הפניה מהשורש, או מעבירים את ה־DNS ל־Cloudflare.

ההפצה עצמה נשארת בחינם. התשלום היחיד הוא חידוש הדומיין אצל הרשם, לא אצל Cloudflare.

בנייה מקומית נשארת בלי תיקיית המאגר, כדי ש־`http://127.0.0.1:4391/` ימשיך לעבוד. הבנייה ב־GitHub מוסיפה את הנתיב `/dr-evelyn-mamber-site`.

## ניווט למרפאה

כפתורי «ניווט ב-Waze» ו«ניווט ב-Google Maps» מופיעים בעמוד צור קשר, בתחתית כל עמוד, ובתשובת המענה על כתובת.
בטלפון הם פותחים את היישום. הקישור של Waze הוא `https://waze.com/ul?ll=קו־רוחב,קו־אורך&navigate=yes` לפי `lat` ו־`lng`. בלי קואורדינטות הוא עובר לחיפוש לפי הכתובת. Google Maps נפתח למסלול אל הכתובת, ואם ב־`googleReviewUrl` יש `placeid` הוא ננעל לכרטיס הזה.

במחשב (עכבר, או מערכת הפעלה של מחשב כשאין מסך מגע) הכפתור של Waze פותח חלון. השדה הראשי הוא מספר נייד ישראלי. «שליחה בוואטסאפ» פותחת `https://wa.me/972…?text=` עם קישור הניווט, ו«שליחה ב-SMS» פותחת `sms:+972…?body=`. המספר לא נשמר בדפדפן ולא נשלח לשרת של האתר. מתחת לזה, באפשרויות הנוספות, יש העתקת קישור וקוד QR. הקוד נוצר בזמן הבנייה מתוך אותו קישור, בלי שירות חיצוני.

`navShareMode`:

- `client` — ברירת המחדל. נפתח וואטסאפ או SMS במכשיר.
- `api` — לחיבור עתידי לשרת הודעות (למשל פונקציית serverless). חובה למלא `navShareEndpoint` בכתובת `https`. בלחיצה האתר שולח `POST` עם הגוף `{ "to": "9725XXXXXXXX", "channel": "whatsapp" או "sms", "text": "…" }`. השרת צריך לאפשר קריאה מהדומיין של האתר. בלי כתובת https הבנייה נעצרת. במצב הזה המספר נשלח רק לאותו שרת, והאתר לא שומר עותק.

## ביקורת בגוגל

`googleReviewUrl` הוא הקישור של «כתיבת ביקורת בגוגל» בדף הבית, בעמוד צור קשר, ובמענה. הניסוח באתר לא מבקש ציון, לא מבקש רק ביקורת חיובית, ולא מציע הטבה.

הערך הנוכחי:

`https://search.google.com/local/writereview?placeid=ChIJXbLbayXXAhURe7YL--N1iNA`

זה Place ID של כרטיס המרפאה במפות גוגל בכתובת חזקיהו המלך 36. כדי להחליף בקישור הקצר הרשמי מפרופיל העסק: נכנסים לגוגל ביזנס → שתפו → בקשו ביקורות → מעתיקים את הקישור שמסתיים ב־`/review` (בדרך כלל `g.page/r/…/review`) ומדביקים אותו במקום כל הכתובת ב־`googleReviewUrl`. אחרי שמירה צריך לבנות מחדש.

## Vercel במקום Cloudflare

1. [vercel.com](https://vercel.com) → Add New → Project → מייבאים את המאגר.
2. Framework: Astro. Build: `npm run build`. Output: `dist`.
3. Domains → מוסיפים את הדומיין ואת הרשומות שהמסך מציג אצל הרשם.

אין צורך בחשבון בתשלום.

## נגישות

האתר נכתב לכיוון ת״י 5568 ו־WCAG 2.1 ברמת AA: מבנה כותרות, דילוג לתוכן, מקלדת, ניגודיות, טפסים עם תוויות, ושפה מסומנת.
הצהרת הנגישות נמצאת ב־`/accessibility/`.
פרטי גישה פיזית למרפאה (מעלית, מדרגות, חניה) חסרים עד שתמלא אותם בקובץ ההגדרות.

## תיקיית שיווק

ב־`marketing/` יש טקסטים מוכנים להדבקה: גוגל ביזנס, וואטסאפ, בקשת משוב, ולוח פוסטים לארבעה שבועות.
אחרי שינוי טלפון או כתובת מעדכנים גם אותם. הם לא מתעדכנים לבד.
